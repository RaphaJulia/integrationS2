# Rapport — TD3

## Points clés

### 1. Modèle

Ce modèle fonctionne sur un shéma de quelque chose, qui fait quelque chose, pour un résultat final. Par exemple, un clic sur un bouton > qui active sur le body une classe .accessibilité > changement du css pour un thème plus contrasté

### 2. classList.toggle

Le classList.toggle est la passerelle entre le JS et le CSS car il permet de faire des changements sur le CSS grâce au JS tout en gardant le rôle initiale des deux langages le comportement pour l'un, l'appraence pour l'autre.
